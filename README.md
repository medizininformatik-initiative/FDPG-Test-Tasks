# FDPG-Test-Tasks
Zur besseren Koordination und Nachverfolgung von Test- und Entwicklungsaufgaben


## Zusammenarbeit

- Standorte weisen sich Aufgaben selbst zu.
- Das Ergebniss der Testung bitte als Kommentar (gegebenenfalls mit Verweis auf daraus entstandene Issues) im Issue direkt dokumentieren
- Der Aufwand (in Stunden) bitte stets als Kommentar im jeweiligen Issue hinterlegen.
- Bei Rückfragen bitte **@bkabaoglu** oder **@kleinertp** markieren.

## Skripte

Fertige Skripte finden sich in der Skriptlibrary:
👉 [medizininformatik-initiative/Skriptlibrary-FDPG](https://github.com/medizininformatik-initiative/Skriptlibrary-FDPG)

Issues zu den Skripten stellt ihr bitte direkt dort.

Zusätzliche, eigene Bedarfe an Entwicklungsskripten, die auch für andere Standorte nachnutzbar sind, könnt ihr gerne selbst in diesem Repository (Test-Tasks) anlegen.
